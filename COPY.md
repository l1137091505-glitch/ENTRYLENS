# Copy facts

- What it is: a BOT Chain account diagnostic interface.
- Observable checks: RPC response, chain ID, address format, bytecode, balance, transaction nonce, canonical EntryPoint v0.6/v0.7 code, optional wallet signature and optional registry code.
- Main action: Run account checks.
- Stored on-chain: reporter, report hash, pass count, total count, timestamp and a short client label.
- Explicit limit: a diagnostic pass is not an audit or formal ERC-4337 certification.
- No invented customer names, testimonials, adoption numbers or performance claims are used.
