# ENTRYLENS product and design plan

1. Product: a BOT Chain ERC-4337 account diagnostic interface. It checks observable network and account facts; it does not claim full protocol certification.
2. Visual system: warm-black-gold palette with Manrope and JetBrains Mono. The first dealt blue palette was rejected because this series already contains several blue interfaces; gold provides the requested new visual identity. Dealt hero: cropped UI collage. Layout: left narrative, right clipped diagnostic terminal, followed by a full-width method rail and split scanner matrix.
3. Voice: technical-dry. Exact, not promotional; short labels, explicit limitations, no invented performance claims.
4. Main action: Run account checks.
5. Wallet path: EIP-6963 list → legacy injected provider → mobile MetaMask deep link; explicit BOT Chain switch/add; account and chain listeners.
6. On-chain path: optional registry stores report hash, score, reporter and timestamp only.
7. Responsive behavior: desktop collage becomes a compact terminal; the scanner stacks before 1100px; check rows become two-line records on phones.
8. Motion: quiet button/underline transitions only. Reduced-motion preferences are respected. The dealt liquid-type and iris moments were not used because they add no diagnostic value and would make the interface less legible.
